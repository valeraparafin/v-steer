A sleeping remote now wakes with a button press, Zwift open or not. **Download `V-Steer.exe` below** and replace your old one; your settings stay.

V-Steer 0.2.1 tells you about this release by itself: a notification and **Download** in the menu.

## Wake the remote with a button

- **Press any button to bring it back** ([#39](https://github.com/valeraparafin/v-steer/issues/39)):
  - with no Zwift for 10 min, V-Steer still lets the remote go so it can sleep and save its charge;
  - before, it came back only when Zwift connected; now a button press wakes it and it reconnects in a few seconds;
  - not used after that? With still no Zwift, V-Steer lets it go again after 10 min.
- **"Charge it soon", not "replace it":** the VS200 is rechargeable, and the low-battery notification now says so.

## Under the hood

- **Settings in one place:** one table now writes, reads and checks `config.toml`, so new settings can't get lost on the way ([#22](https://github.com/valeraparafin/v-steer/issues/22)). Your file keeps its settings; only the spacing before comments may change.
- **A lighter tray:** the menu is rebuilt only when something in it changes, and the Start with Windows state is no longer read from the registry on every update ([#31](https://github.com/valeraparafin/v-steer/issues/31), [#32](https://github.com/valeraparafin/v-steer/issues/32)).
- **Smaller fixes:** a newly picked remote shows at once in the status ([#30](https://github.com/valeraparafin/v-steer/issues/30)); Ctrl+C when run from source shuts down cleanly ([#28](https://github.com/valeraparafin/v-steer/issues/28)).

## Good to know

- **Pairing once per ride:** if V-Steer starts before Zwift (for example with Windows), pick **KICKR BIKE PRO 1337** under **Paired Devices → Controls** each ride. Zwift restores only Bluetooth devices by itself, not Wi-Fi ones like V-Steer ([#10](https://github.com/valeraparafin/v-steer/issues/10)).
