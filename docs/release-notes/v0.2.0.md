V-Steer now lives in the tray: no more console window. **Download `V-Steer.exe` below** and replace your old one; your settings stay.

V-Steer 0.1.x tells you about this release by itself when it starts.

## The tray

- **An icon next to the clock instead of a window.** It shows at a glance whether you can steer ([#11](https://github.com/valeraparafin/v-steer/issues/11)):

  | icon | means |
  |------|-------|
  | <img src="https://raw.githubusercontent.com/valeraparafin/v-steer/v0.2.0/docs/tray/ready.png" width="24"> | ready: the remote and Zwift are connected |
  | <img src="https://raw.githubusercontent.com/valeraparafin/v-steer/v0.2.0/docs/tray/partial.png" width="24"> | one of them is connected; hover the icon to see which |
  | <img src="https://raw.githubusercontent.com/valeraparafin/v-steer/v0.2.0/docs/tray/idle.png" width="24"> | neither is connected yet |
  | <img src="https://raw.githubusercontent.com/valeraparafin/v-steer/v0.2.0/docs/tray/error.png" width="24"> | V-Steer can't steer; **Open log** says why |

- **Everything from the right-click menu:**
  - **Swap + and −** and **Pick another remote…**, with no editing of `config.toml`;
  - **Start with Windows**;
  - **Open log**, **Open settings folder**, **Help**;
  - **Download**, shown when a new version is out;
  - **Quit**, which removes the device from Zwift's list.
- **Notifications, each at most once per run:**
  - on first run, which remote to press and what to pair in Zwift;
  - a new version;
  - an error that stops steering.
- **Started V-Steer twice?** The second copy says it is already running and leaves.
- **Want the old log window?** Start `V-Steer.exe --console`.

## Good to know

- **Automatic pairing:** if V-Steer starts before Zwift (for example with Windows), pick **KICKR BIKE PRO 1337** under **Paired Devices → Controls** once per ride. Started while Zwift is open, it pairs by itself. A fix is planned for the next version ([#10](https://github.com/valeraparafin/v-steer/issues/10)).
- **Release how-to:** a step-by-step guide is in [How it works](https://github.com/valeraparafin/v-steer/blob/main/docs/how-it-works.md#release) ([#26](https://github.com/valeraparafin/v-steer/pull/26)).
