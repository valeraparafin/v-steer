# vs200-steer v0.1 (console) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A console app, run from source on Windows, that turns taps on a ThinkRider VS200 into Zwift steering by emulating a Zwift Ride controller over the network.

**Architecture:** `asyncio` app with four isolated units — VS200 BLE input (`vs200.py`), Zwift Ride emulator over DirCon/mDNS (`zwift/`), LAN address picker (`net.py`), config (`config.py`) — wired by `core.py` and shown by a console UI. Protocol bytes are pure functions tested against golden bytes captured in the 2026-10-13 spike.

**Tech Stack:** Python 3.11, `bleak` (BLE/WinRT), `zeroconf` (mDNS, brings `ifaddr`), `pytest` + `pytest-asyncio`, `ruff`.

**Spec:** `docs/superpowers/specs/2026-10-13-vs200-steer-design.md` (milestone 1 only; CI/releases and tray are later plans).

## Global Constraints

- Python `>=3.11`; runtime dependencies exactly `bleak>=0.22`, `zeroconf>=0.130` (nothing else at runtime).
- Windows only. Run from source: `setup.cmd` once, then `run.cmd`.
- License MIT. `src/vs200steer/zwift/dircon.py` is vendored from ZwiftBridge (MIT) — keep its copyright notice; credit in `NOTICE`.
- Config file: `%APPDATA%\vs200-steer\config.toml`; log file: `%APPDATA%\vs200-steer\vs200-steer.log` (rotating).
- DirCon TCP port: first free in `36866…36875`. mDNS type `_wahoo-fitness-tnp._tcp`, default instance name `KICKR BIKE PRO 1337`.
- mDNS TXT exactly: `ble-service-uuids=FC82`, `mac-address=50-50-25-6C-66-9C`, `serial-number=244700181`, `manufacturer-data=094A0BAAAA`.
- DirCon property bits (not GATT): SYNC_RX `0x02`, ASYNC `0x04`, SYNC_TX `0x04`.
- Steering is D-pad: left `2308feffffff0f`, right `2308fbffffff0f`, released `2308ffffffff0f`; pulse default 200 ms, re-sent every 50 ms; keepalive = released frame every 20 s while idle.
- Default mapping: VS200 `+` = right, `−` = left; `swap = true` inverts.
- Code, comments, logs, README in English. Conventional commits, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- All commands below run from `C:\Git\vs200-steer` in PowerShell.

## Review Focus

1. **Zwift reconnects mid-ride** (it did so every 20–80 s in the spike) → the next tap must reach the new connection, not the dead one. Test: Task 3 `test_pulses_reach_a_reconnected_client`.
2. **Tap while Zwift is not connected/ready** → tap is dropped and logged, nothing raises, later taps still work. Tests: Task 3 `test_pulse_without_ready_client_returns_false`, Task 7 `test_dropped_pulse_is_logged`.
3. **Taps faster than the pulse length** → each tap is its own press/release, in order, never merged or reordered. Test: Task 3 `test_rapid_taps_are_serialized`.
4. **VS200 asleep at start or dropping mid-ride** → app keeps searching and reconnects by itself; taps after reconnect work. Test: Task 4 `test_reconnects_after_sleep_and_drop`.
5. **Broken or out-of-range config** → app exits with a message naming the file and the bad key, not a traceback. Tests: Task 6 `test_corrupt_file_raises_config_error_with_path`, `test_pulse_ms_out_of_range_rejected`.

```python
"""Zwift Ride controller protocol as Zwift expects it over DirCon.

Every constant here was verified against Zwift on 2026-10-13 (see the design spec).
"""

from __future__ import annotations

from ..events import Tap

RIDE_SERVICE_UUID = "0000fc82-0000-1000-8000-00805f9b34fb"
ASYNC_CHAR_UUID = "00000002-19ca-4651-86e5-fa29dcdd09d1"    # notify: button state
SYNC_RX_CHAR_UUID = "00000003-19ca-4651-86e5-fa29dcdd09d1"  # write: commands from Zwift
SYNC_TX_CHAR_UUID = "00000004-19ca-4651-86e5-fa29dcdd09d1"  # notify: replies to Zwift

# DirCon's own property bits. GATT bits (write 0x08, notify 0x10) make Zwift
# subscribe to SYNC_RX only, and nothing works.
DIRCON_PROP_WRITE = 0x02
DIRCON_PROP_NOTIFY = 0x04

MDNS_SERVICE_TYPE = "_wahoo-fitness-tnp._tcp.local."
DEFAULT_DEVICE_NAME = "KICKR BIKE PRO 1337"
# Without manufacturer-data (Zwift Inc 0x094A, type 0x0B) Zwift does not list the device.
MDNS_TXT = {
    "ble-service-uuids": b"FC82",
    "mac-address": b"50-50-25-6C-66-9C",
    "serial-number": b"244700181",
    "manufacturer-data": b"094A0BAAAA",
}

RIDE_ON = b"RideOn"
RIDE_ON_REPLY = b"RideOn\x01\x03"

OP_GET = 0x00
OP_GET_RESPONSE = 0x3C
OP_RIDE_KEYPAD = 0x23

# D-pad bits in the Ride button map; buttons are active low (bit clear = pressed).
_DPAD_MASKS = {Tap.LEFT: 0x01, Tap.RIGHT: 0x04}


def _varint(value: int) -> bytes:
    out = bytearray()
    while True:
        byte = value & 0x7F
        value >>= 7
        out.append(byte | 0x80 if value else byte)
        if not value:
            return bytes(out)


def _read_varint(buf: bytes, i: int) -> tuple[int, int]:
    value, shift = 0, 0
    while True:
        if i >= len(buf):
            raise ValueError("truncated varint")
        byte = buf[i]
        i += 1
        value |= (byte & 0x7F) << shift
        if not byte & 0x80:
            return value, i
        shift += 7


def _pb_uint(field: int, value: int) -> bytes:
    return _varint(field << 3) + _varint(value)


def _pb_bytes(field: int, value: bytes) -> bytes:
    return _varint((field << 3) | 2) + _varint(len(value)) + value


def keypad_frame(direction: Tap | None) -> bytes:
    """RideKeyPadStatus {1: buttonMap} with the D-pad bit for `direction` cleared."""
    button_map = 0xFFFFFFFF
    if direction is not None:
        button_map &= ~_DPAD_MASKS[direction]
    return bytes([OP_RIDE_KEYPAD]) + _pb_uint(1, button_map)


RELEASED_FRAME = keypad_frame(None)


def parse_get(value: bytes) -> int | None:
    """dataObjectId of a GET (opcode 0x00, protobuf {1: id}), or None if not a GET."""
    if len(value) < 2 or value[0] != OP_GET:
        return None
    i = 1
    try:
        while i < len(value):
            key, i = _read_varint(value, i)
            if key & 0x07 != 0:
                return None
            field_value, i = _read_varint(value, i)
            if key >> 3 == 1:
                return field_value
    except ValueError:
        return None
    return None


def _get_response(object_id: int, data: bytes) -> bytes:
    return bytes([OP_GET_RESPONSE]) + _pb_uint(1, object_id) + _pb_bytes(2, data)


GET_REPLIES: dict[int, bytes] = {
    # PAGE_DEV_INFO: BikeControl's captured "Zwift Click2" page, verified with Zwift.
    0: bytes.fromhex(
        "3c080012460a440883041204000001011a0b5a7769667420436c69636b320f30422d3538443135414242343336333a"
        "03422e304204080210014801500b5a0c353844313541424234333633"
    ),
    # PAGE_CLIENT_SERVER_CONFIGURATION {notifications: 0}
    16: _get_response(16, _pb_uint(1, 0)),
    # PAGE_CONTROLLER_INPUT_CONFIG {supportedDigitalInputs: 4607, supportedAnalogInputs: 0}
    1024: _get_response(1024, _pb_uint(1, 4607) + _pb_uint(2, 0)),
    # BATTERY_STATE {chgState: IDLE, percLevel: 100, timeToEmpty: 0, timeToFull: 0}
    771: _get_response(771, _pb_uint(1, 0) + _pb_uint(2, 100) + _pb_uint(3, 0) + _pb_uint(4, 0)),
}
```

```python
import asyncio

import pytest

from vs200steer.events import Tap

from vs200steer.zwift import protocol as P
from vs200steer.zwift.ride import EmulatorState, RideEmulator

DISCOVER_CHARACTERISTICS_GOLDEN = (
    "0102010000430000fc8200001000800000805f9b34fb0000000319ca465186e5fa29dcdd09d1020000000219ca465186e5"
    "fa29dcdd09d1040000000419ca465186e5fa29dcdd09d104"

class FakeZwift:
    """A TCP client that speaks DirCon the way Zwift did in the 2026-10-13 spike."""

    def __init__(self, reader, writer):
        self.reader, self.writer, self.seq, self.buffer = reader, writer, 0, b""

    @classmethod
    async def connect(cls, port):
        return cls(*await asyncio.open_connection("127.0.0.1", port))

    async def send(self, identifier, payload=b""):
        self.writer.write(dircon.Packet(identifier, self.seq, 0, payload).encode())
        self.seq = (self.seq + 1) % 256
        await self.writer.drain()

    async def recv(self, timeout=1.0):
        while True:
            pkt, self.buffer = dircon.decode(self.buffer)
            if pkt is not None:
                return pkt
            chunk = await asyncio.wait_for(self.reader.read(4096), timeout)
            if not chunk:
                raise ConnectionError("server closed")
            self.buffer += chunk

    async def drain_packets(self, quiet=0.2):
        packets = []
        while True:
            try:
                packets.append(await self.recv(timeout=quiet))
            except asyncio.TimeoutError:
                return packets

    async def session(self):
        """DISCOVER_SERVICES, DISCOVER_CHARACTERISTICS, ENABLE ASYNC, ENABLE SYNC_TX."""
        await self.send(dircon.MSG_DISCOVER_SERVICES)
        services = await self.recv()
        await self.send(dircon.MSG_DISCOVER_CHARACTERISTICS, dircon.uuid_bytes(P.RIDE_SERVICE_UUID))
        characteristics = await self.recv()
        for uuid in (P.ASYNC_CHAR_UUID, P.SYNC_TX_CHAR_UUID):
            await self.send(dircon.MSG_ENABLE_NOTIFICATIONS, dircon.uuid_bytes(uuid) + b"\x01")
            await self.recv()
        return services, characteristics

    async def write_sync_rx(self, value):
        await self.send(dircon.MSG_WRITE_CHARACTERISTIC, dircon.uuid_bytes(P.SYNC_RX_CHAR_UUID) + value)

    async def close(self):
        self.writer.close()


def frames(packets):
    """ASYNC notification values, consecutive duplicates collapsed."""
    out = []
    for p in packets:
```

```python
"""Emulate a Zwift Ride controller over DirCon so Zwift pairs with it under Controls."""

from __future__ import annotations

import asyncio
import logging
import socket
from enum import Enum
from typing import Callable

from ..events import Tap
from . import dircon
from . import protocol as P

log = logging.getLogger("vs200steer")

PORT_RANGE = 10
NAME_ATTEMPTS = 5


class EmulatorState(Enum):
    STOPPED = "stopped"
    ADVERTISING = "advertising"
    CONNECTED = "connected"
    READY = "ready"


class RideEmulator:
    def __init__(self, address: str, port: int = 36866, device_name: str = P.DEFAULT_DEVICE_NAME, *,
                 advertise: bool = True, keepalive_s: float = 20.0, repeat_s: float = 0.05,
                 gap_s: float = 0.05) -> None:
        self.address = address
        self.port = port
        self.device_name = device_name
        self.advertise = advertise
        self.keepalive_s = keepalive_s
        self.repeat_s = repeat_s
        self.gap_s = gap_s
        self.bound_port: int | None = None
        self.advertised_name: str | None = None
        self.on_state_change: Callable[[EmulatorState], None] | None = None
        self._state = EmulatorState.STOPPED
        self._server: asyncio.AbstractServer | None = None
        self._zeroconf = None
        self._service_info = None
        self._keepalive_task: asyncio.Task | None = None
        self._pulse_lock = asyncio.Lock()
        self._background: set[asyncio.Task] = set()
        self.dircon = dircon.DirconServer(
            dircon.Service(P.RIDE_SERVICE_UUID, [
                dircon.Characteristic(P.SYNC_RX_CHAR_UUID, P.DIRCON_PROP_WRITE, on_write=self._on_sync_write),
                dircon.Characteristic(P.ASYNC_CHAR_UUID, P.DIRCON_PROP_NOTIFY, on_read=lambda: P.RELEASED_FRAME),
                dircon.Characteristic(P.SYNC_TX_CHAR_UUID, P.DIRCON_PROP_NOTIFY),
            ]),
            on_client_change=lambda _message: self._refresh_state(),
        )

    # --- state ---------------------------------------------------------------

    @property
    def state(self) -> EmulatorState:
        return self._state

    def _refresh_state(self) -> None:
        if self._server is None:
            new = EmulatorState.STOPPED
        elif self.dircon.subscribers(P.ASYNC_CHAR_UUID):
            new = EmulatorState.READY
        elif self.dircon.clients:
            new = EmulatorState.CONNECTED
        else:
            new = EmulatorState.ADVERTISING
        if new is not self._state:
            self._state = new
            log.info("Zwift link: %s", new.value)
            if self.on_state_change:
                self.on_state_change(new)

    # --- lifecycle -----------------------------------------------------------

    async def start(self) -> None:
        ports = [0] if self.port == 0 else range(self.port, self.port + PORT_RANGE)
        last_error: OSError | None = None
        for port in ports:
            try:
                self._server = await asyncio.start_server(self.dircon.handle_client, "0.0.0.0", port)
                break
            except OSError as exc:
                last_error = exc
        if self._server is None:
            raise last_error or OSError("no free DirCon port")
        self.bound_port = self._server.sockets[0].getsockname()[1]
        if self.advertise:
            await self._advertise()
        self._keepalive_task = asyncio.create_task(self._keepalive_loop())
        self._refresh_state()

    async def _advertise(self) -> None:
        from zeroconf import NonUniqueNameException, ServiceInfo
        from zeroconf.asyncio import AsyncZeroconf

        self._zeroconf = AsyncZeroconf()
        for attempt in range(NAME_ATTEMPTS):
            name = self.device_name if attempt == 0 else f"{self.device_name} {attempt + 1}"
            label = "".join(c if c.isalnum() else "-" for c in name).strip("-").lower() or "vs200-steer"
            info = ServiceInfo(
                P.MDNS_SERVICE_TYPE,
                f"{name}.{P.MDNS_SERVICE_TYPE}",
                addresses=[socket.inet_aton(self.address)],
                port=self.bound_port,
                properties=P.MDNS_TXT,
                server=f"{label}.local.",
            )
            try:
                await self._zeroconf.async_register_service(info, strict=False)
            except NonUniqueNameException:
                log.info("mDNS name '%s' is taken, trying another", name)
                continue
            self._service_info = info
            self.advertised_name = name
            return
        raise RuntimeError(f"could not register an mDNS name based on '{self.device_name}'")

    async def stop(self) -> None:
        if self._keepalive_task:
            self._keepalive_task.cancel()
            try:
                await self._keepalive_task
            except asyncio.CancelledError:
                pass
            self._keepalive_task = None
        if self._zeroconf:
            if self._service_info:
                try:
                    await self._zeroconf.async_unregister_service(self._service_info)
                except Exception:  # noqa: BLE001 - teardown must not raise
                    pass
            await self._zeroconf.async_close()
            self._zeroconf = None
            self._service_info = None
        await self.dircon.close()
        if self._server:
            self._server.close()
            await self._server.wait_closed()
            self._server = None
        self._refresh_state()

    # --- Zwift -> us ---------------------------------------------------------

    def _on_sync_write(self, value: bytes) -> None:
        if value.startswith(P.RIDE_ON):
            log.debug("RideOn from Zwift")
            self._spawn(self._send(P.SYNC_TX_CHAR_UUID, P.RIDE_ON_REPLY))
            return
        object_id = P.parse_get(value)
        if object_id is None:
            log.debug("ignored SYNC_RX write %s", value.hex())
            return
        reply = P.GET_REPLIES.get(object_id)
        if reply is None:
            log.info("Zwift asked for data object %d, not served", object_id)
            return
        log.debug("GET %d answered", object_id)
        self._spawn(self._send(P.SYNC_TX_CHAR_UUID, reply))

    async def _send(self, char_uuid: str, value: bytes) -> int:
        """notify() that never raises: a half-dead Zwift socket must not kill a pulse or the keepalive."""
        try:
            return await self.dircon.notify(char_uuid, value)
        except (ConnectionError, OSError) as exc:
            log.info("Zwift link write failed: %s", exc)
            return 0

    def _spawn(self, coro) -> None:
        task = asyncio.get_running_loop().create_task(coro)
        self._background.add(task)
        task.add_done_callback(self._background.discard)

    # --- us -> Zwift ---------------------------------------------------------

    async def pulse(self, direction: Tap, ms: int) -> bool:
        """Hold the D-pad `direction` for `ms`, then release. Pulses run one at a time, in order."""
        async with self._pulse_lock:
            if self._state is not EmulatorState.READY:
                return False
            frame = P.keypad_frame(direction)
            loop = asyncio.get_running_loop()
            end = loop.time() + ms / 1000
            while True:
                await self._send(P.ASYNC_CHAR_UUID, frame)
                remaining = end - loop.time()
                if remaining <= 0:
                    break
                await asyncio.sleep(min(self.repeat_s, remaining))
            await self._send(P.ASYNC_CHAR_UUID, P.RELEASED_FRAME)
            await asyncio.sleep(self.gap_s)
            return True

    async def _keepalive_loop(self) -> None:
        while True:
            await asyncio.sleep(self.keepalive_s)
            if self._state is EmulatorState.READY and not self._pulse_lock.locked():
                await self._send(P.ASYNC_CHAR_UUID, P.RELEASED_FRAME)
```

```python
"""ThinkRider VS200 input: one BLE notification per press on 0xFEA1, no repeat, no release."""

from __future__ import annotations

import asyncio
import logging
from enum import Enum
from typing import Callable

from .events import Tap

log = logging.getLogger("vs200steer")

NAME_PREFIX = "THINK VS"
FEA1_UUID = "0000fea1-0000-1000-8000-00805f9b34fb"
_PACKETS = {
    bytes.fromhex("f3050301fc"): Tap.RIGHT,  # "+" button
    bytes.fromhex("f3050300fb"): Tap.LEFT,   # "-" button
}
_BLE_ERRORS: tuple[type[BaseException], ...] = (OSError, asyncio.TimeoutError)
try:  # bleak is a runtime dependency; tests inject fakes but bleak is installed anyway
    from bleak.exc import BleakError

    _BLE_ERRORS = (*_BLE_ERRORS, BleakError)
except ImportError:  # pragma: no cover
    pass


def parse_packet(data: bytes) -> Tap | None:
    return _PACKETS.get(bytes(data))


class InputState(Enum):
    SEARCHING = "searching"
    CONNECTED = "connected"


async def _bleak_find(address: str, timeout: float):
    from bleak import BleakScanner

    return await BleakScanner.find_device_by_address(address, timeout=timeout)


async def _bleak_scan(timeout: float):
    from bleak import BleakScanner

    devices = await BleakScanner.discover(timeout=timeout)
    return [d for d in devices if (d.name or "").upper().startswith(NAME_PREFIX)]


def _bleak_client(device, disconnected_callback):
    from bleak import BleakClient

    return BleakClient(device, disconnected_callback=disconnected_callback)


async def pick_remote(timeout: float = 120.0, *, scan=None, client_factory=None) -> str | None:
    """Connect to every VS200 in range and return the address of the first one pressed."""
    scan = scan or _bleak_scan
    client_factory = client_factory or _bleak_client
    loop = asyncio.get_running_loop()
    deadline = loop.time() + timeout
    chosen: asyncio.Future[str] = loop.create_future()
    clients, seen = [], set()

    def make_handler(address: str):
        def handler(_sender, data) -> None:
            if not chosen.done() and parse_packet(bytes(data)) is not None:
                chosen.set_result(address)
        return handler

    try:
        while not chosen.done() and loop.time() < deadline:
            for device in await scan(5.0):
                if device.address in seen:
                    continue
                seen.add(device.address)
                log.info("Found %s (%s) — press a button on it to use it", device.name, device.address)
                client = client_factory(device, disconnected_callback=lambda _c: None)
                try:
                    await client.connect()
                    await client.start_notify(FEA1_UUID, make_handler(device.address))
                    clients.append(client)
                except _BLE_ERRORS as exc:
                    log.info("Could not connect to %s: %s", device.address, exc)
                    seen.discard(device.address)
            if not chosen.done():
                try:
                    await asyncio.wait_for(asyncio.shield(chosen), min(1.0, max(0.0, deadline - loop.time())))
                except asyncio.TimeoutError:
                    pass
        return chosen.result() if chosen.done() else None
    finally:
        for client in clients:
            try:
                await client.disconnect()
            except Exception:  # noqa: BLE001 - best effort
                pass


class Vs200Input:
    def __init__(self, address: str, on_tap: Callable[[Tap], None],
                 on_state: Callable[[InputState], None] | None = None, *, find_device=None,
                 client_factory=None, retry_s: float = 3.0, max_retry_s: float = 15.0) -> None:
        self.address = address
        self.on_tap = on_tap
        self.on_state = on_state
        self._find = find_device or _bleak_find
        self._client_factory = client_factory or _bleak_client
        self.retry_s = retry_s
        self.max_retry_s = max_retry_s
        self._state: InputState | None = None

    @property
    def state(self) -> InputState | None:
        return self._state

    def _set_state(self, state: InputState) -> None:
        if state is not self._state:
            self._state = state
            log.info("VS200 %s: %s", self.address, state.value)
            if self.on_state:
                self.on_state(state)

    def _on_notify(self, _sender, data) -> None:
        tap = parse_packet(bytes(data))
        if tap is None:
            log.debug("VS200 unknown packet %s", bytes(data).hex())
            return
        self.on_tap(tap)

    async def run(self) -> None:
        delay = self.retry_s
        while True:
            self._set_state(InputState.SEARCHING)
            device = await self._find(self.address, 10.0)
            if device is None:
                await asyncio.sleep(delay)  # asleep or out of range: press a button to wake it
                delay = min(delay * 2, self.max_retry_s)
                continue
            delay = self.retry_s
            disconnected = asyncio.Event()
            client = self._client_factory(device, disconnected_callback=lambda _c: disconnected.set())
            try:
                await client.connect()

                self._set_state(InputState.CONNECTED)

                log.info("VS200 connection failed: %s", exc)
            finally:
                try:
                    await client.disconnect()
                except Exception:  # noqa: BLE001 - already gone
                    pass
            await asyncio.sleep(self.retry_s)
```

```python
"""Pick the LAN IPv4 address Zwift can reach us on (skip VPN, virtual and link-local adapters)."""

from __future__ import annotations

import ipaddress
import re
import socket
from dataclasses import dataclass

_VIRTUAL = re.compile(
    r"vpn|tap|tun|wireguard|wintun|hyper-v|vethernet|virtual|bluetooth|loopback|wsl|docker|vmware|"
    r"virtualbox|zerotier|tailscale|npcap",
    re.IGNORECASE,
)


@dataclass
class Adapter:
    name: str
    ips: list[str]


def list_adapters() -> list[Adapter]:
    import ifaddr

    return [
        Adapter(a.nice_name, [ip.ip for ip in a.ips if isinstance(ip.ip, str)])
        for a in ifaddr.get_adapters()
    ]


def default_route_ip() -> str | None:
    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        sock.connect(("8.8.8.8", 80))  # no packet is sent; this only consults the routing table
        return sock.getsockname()[0]
    except OSError:
        return None
    finally:
        sock.close()


def _usable(ip: str) -> bool:
    addr = ipaddress.ip_address(ip)
    return addr.version == 4 and addr.is_private and not addr.is_loopback and not addr.is_link_local


def pick_address(adapters: list[Adapter], route_ip: str | None) -> str | None:
    candidates = [ip for a in adapters if not _VIRTUAL.search(a.name) for ip in a.ips if _usable(ip)]
    if route_ip in candidates:
        return route_ip
    return candidates[0] if candidates else None
```

```python
"""%APPDATA%\\vs200-steer\\config.toml — read with tomllib, written from a fixed template."""

from __future__ import annotations

import json
import os
import tomllib
from dataclasses import dataclass
from pathlib import Path

from .zwift.protocol import DEFAULT_DEVICE_NAME

PULSE_MIN_MS, PULSE_MAX_MS = 50, 2000


@dataclass
class Config:
    vs200_address: str = ""
    swap: bool = False
    pulse_ms: int = 200
    device_name: str = DEFAULT_DEVICE_NAME
    network_address: str = ""


class ConfigError(Exception):
    pass


def default_path() -> Path:
    return Path(os.environ.get("APPDATA", str(Path.home()))) / "vs200-steer" / "config.toml"


_TEMPLATE = """\
[vs200]
address = {vs200_address}   # filled on first run
swap = {swap}               # false: + = right, - = left

[steer]
pulse_ms = {pulse_ms}       # how long one tap holds the D-pad ({min}..{max})

[zwift]
device_name = {device_name}

[network]
address = {network_address}   # empty = auto
"""


def save(cfg: Config, path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(
        _TEMPLATE.format(
            vs200_address=json.dumps(cfg.vs200_address),
            swap="true" if cfg.swap else "false",
            pulse_ms=cfg.pulse_ms,
            min=PULSE_MIN_MS,
            max=PULSE_MAX_MS,
            device_name=json.dumps(cfg.device_name),
            network_address=json.dumps(cfg.network_address),
        ),
        encoding="utf-8",
    )


def _get(data: dict, section: str, key: str, kind: type, default, path: Path):
    value = data.get(section, {}).get(key, default)
    if kind is int and isinstance(value, bool) or not isinstance(value, kind):
        raise ConfigError(f"{path}: {section}.{key} must be {kind.__name__}, got {value!r}")
    return value


def load(path: Path) -> Config:
    if not path.exists():
        cfg = Config()
        save(cfg, path)
        return cfg
    try:
        data = tomllib.loads(path.read_text(encoding="utf-8"))
    except (tomllib.TOMLDecodeError, UnicodeDecodeError) as exc:
        raise ConfigError(f"{path}: {exc}") from exc
    defaults = Config()
    cfg = Config(
        vs200_address=_get(data, "vs200", "address", str, defaults.vs200_address, path),
        swap=_get(data, "vs200", "swap", bool, defaults.swap, path),
        pulse_ms=_get(data, "steer", "pulse_ms", int, defaults.pulse_ms, path),
        device_name=_get(data, "zwift", "device_name", str, defaults.device_name, path),
        network_address=_get(data, "network", "address", str, defaults.network_address, path),
    )
    if not PULSE_MIN_MS <= cfg.pulse_ms <= PULSE_MAX_MS:
        raise ConfigError(f"{path}: steer.pulse_ms must be {PULSE_MIN_MS}..{PULSE_MAX_MS}, got {cfg.pulse_ms}")
    return cfg
```

```python
"""Wires VS200 taps to Zwift pulses and keeps the status the UI shows."""

from __future__ import annotations

import asyncio
import logging
from dataclasses import dataclass, replace
from typing import Callable

from .config import Config
from .events import Tap
from .vs200 import InputState
from .zwift.ride import EmulatorState

log = logging.getLogger("vs200steer")


@dataclass(frozen=True)
class Status:
    vs200: InputState = InputState.SEARCHING
    zwift: EmulatorState = EmulatorState.STOPPED
    vs200_address: str = ""


class Core:
    def __init__(self, cfg: Config, emulator) -> None:
        self.cfg = cfg
        self.emulator = emulator
        self.status = Status(vs200_address=cfg.vs200_address)
        self._listeners: list[Callable[[Status], None]] = []
        self._tasks: set[asyncio.Task] = set()

    def subscribe(self, listener: Callable[[Status], None]) -> None:
        self._listeners.append(listener)
        listener(self.status)

    def map_tap(self, tap: Tap) -> Tap:
        if not self.cfg.swap:
            return tap
        return Tap.LEFT if tap is Tap.RIGHT else Tap.RIGHT

    def on_tap(self, tap: Tap) -> None:
        task = asyncio.get_running_loop().create_task(self._steer(self.map_tap(tap)))
        self._tasks.add(task)
        task.add_done_callback(self._tasks.discard)

    async def _steer(self, direction: Tap) -> None:
        delivered = await self.emulator.pulse(direction, self.cfg.pulse_ms)
        if delivered:
            log.info("steer %s", direction.value)
        else:
            log.info("steer %s dropped: Zwift is not connected", direction.value)

    async def wait_idle(self) -> None:
        while self._tasks:
            await asyncio.gather(*list(self._tasks))

    def on_input_state(self, state: InputState) -> None:
        self._update(vs200=state)

    def on_emulator_state(self, state: EmulatorState) -> None:
        self._update(zwift=state)

    def _update(self, **changes) -> None:
        new = replace(self.status, **changes)
        if new != self.status:
            self.status = new
            for listener in self._listeners:
                listener(new)
```

```python
from .zwift.ride import EmulatorState, RideEmulator

log = logging.getLogger("vs200steer")

HINT_AFTER_S = 60
_ERROR_ALREADY_EXISTS = 183
_kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
_kernel32.CreateMutexW.restype = wintypes.HANDLE
_kernel32.CreateMutexW.argtypes = [wintypes.LPVOID, wintypes.BOOL, wintypes.LPCWSTR]
_kernel32.CloseHandle.argtypes = [wintypes.HANDLE]


def acquire_single_instance(name: str = "Local\\vs200-steer") -> int | None:
    handle = _kernel32.CreateMutexW(None, False, name)
    if not handle:
        return None
    if ctypes.get_last_error() == _ERROR_ALREADY_EXISTS:
        _kernel32.CloseHandle(handle)
        return None
    return handle


def release_single_instance(handle: int) -> None:
    _kernel32.CloseHandle(handle)


def should_hint(state: EmulatorState, elapsed_s: float, hinted: bool) -> bool:
    return not hinted and elapsed_s >= HINT_AFTER_S and state is EmulatorState.ADVERTISING


def setup_logging(debug: bool, log_path: Path) -> None:
    log_path.parent.mkdir(parents=True, exist_ok=True)
    log.setLevel(logging.DEBUG if debug else logging.INFO)
    console = logging.StreamHandler()
    console.setFormatter(logging.Formatter("%(asctime)s %(message)s", "%H:%M:%S"))
    file = logging.handlers.RotatingFileHandler(log_path, maxBytes=1_000_000, backupCount=3, encoding="utf-8")
    file.setFormatter(logging.Formatter("%(asctime)s %(levelname)s %(message)s"))
    log.addHandler(console)
    log.addHandler(file)


async def _hint_loop(emulator: RideEmulator) -> None:
    loop = asyncio.get_running_loop()
    started, hinted = loop.time(), False
    while not hinted:
        await asyncio.sleep(5)
        if should_hint(emulator.state, loop.time() - started, hinted):
            hinted = True
            log.warning(
                "Zwift has not connected yet. In Zwift: Paired Devices -> Controls -> pair '%s'. "
                "If it is not listed: allow vs200-steer/Python through Windows Firewall, "
                "check the PC and Zwift are on the same network, or set [network] address in the config.",
                emulator.advertised_name,
            )


async def run(cfg: config.Config, cfg_path: Path) -> int:
    if not cfg.vs200_address:
        log.info("First run: wake the VS200 you want to steer with and press any button on it ...")
        address = await pick_remote(timeout=120)
        if not address:
            log.error("No VS200 was pressed within 2 minutes. Is it awake and not connected to the trainer?")
            return 2
        cfg.vs200_address = address
        config.save(cfg, cfg_path)
        log.info("Saved VS200 %s to %s", address, cfg_path)

    lan = cfg.network_address or net.pick_address(net.list_adapters(), net.default_route_ip())
    if not lan:
        log.error("No LAN address found to advertise on. Set [network] address in %s", cfg_path)
        return 2

    emulator = RideEmulator(lan, device_name=cfg.device_name)
    core = Core(cfg, emulator)
    core.subscribe(ConsoleUI().on_status)
    emulator.on_state_change = core.on_emulator_state
    vs200 = Vs200Input(cfg.vs200_address, on_tap=core.on_tap, on_state=core.on_input_state)

    await emulator.start()
    log.info("Advertising '%s' on %s:%d. In Zwift: Paired Devices -> Controls -> pair it.",
             emulator.advertised_name, lan, emulator.bound_port)
    hint = asyncio.create_task(_hint_loop(emulator))
    try:
        await vs200.run()
    finally:
        hint.cancel()
        await emulator.stop()
    return 0


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="vs200-steer", description="Steer in Zwift with a ThinkRider VS200.")
    parser.add_argument("--debug", action="store_true", help="log the full DirCon traffic")
    parser.add_argument("--config", type=Path, default=None, help="config file path")
    args = parser.parse_args(argv)
    cfg_path = args.config or config.default_path()
    setup_logging(args.debug, cfg_path.parent / "vs200-steer.log")
    log.info("vs200-steer %s", __version__)

    handle = acquire_single_instance()
    if handle is None:
        log.error("vs200-steer is already running.")
        return 1
    try:
        try:
            cfg = config.load(cfg_path)
        except config.ConfigError as exc:
            log.error("Config error: %s", exc)
            return 2
        return asyncio.run(run(cfg, cfg_path))
    except KeyboardInterrupt:
        log.info("Stopped.")
        return 0
    finally:
        release_single_instance(handle)
```

```markdown
# vs200-steer

Steer in Zwift with a ThinkRider VS200 thumb remote: tap `+` to move right, `−` to move left.

vs200-steer connects to a VS200 over Bluetooth and shows up in Zwift as a Zwift Ride controller
over your local network (the same way Wi-Fi trainers do). Your other VS200 can keep shifting
through the trainer as before.

## Requirements

- Windows 10/11 with Bluetooth
- Python 3.11+ (until the .exe release)
- Zwift on this PC, or on another device on the same network

## Setup

    git clone https://github.com/valeraparafin/vs200-steer.git
    cd vs200-steer
    setup.cmd

## Run

    run.cmd

First run: wake the VS200 you want to steer with and press any button — its address is saved to
`%APPDATA%\vs200-steer\config.toml`. Then in Zwift: **Paired Devices → Controls** → pair
**KICKR BIKE PRO 1337** (Wi-Fi icon). Zwift shows "Welcome to steering".

## Config

`%APPDATA%\vs200-steer\config.toml`:

| key | default | meaning |
|-----|---------|---------|
| `vs200.address` | (first run) | which remote to use |
| `vs200.swap` | `false` | `true` makes `+` steer left |
| `steer.pulse_ms` | `200` | how long one tap holds the D-pad (50..2000) |
| `zwift.device_name` | `KICKR BIKE PRO 1337` | name shown in Zwift |
| `network.address` | (auto) | LAN IPv4 to advertise, if auto-detection picks the wrong one |

## Troubleshooting

- **Zwift doesn't list the device**: allow Python (later: vs200-steer.exe) through Windows Firewall
  when asked, including Public networks; make sure Zwift and this PC are on the same network; if
  you use a VPN, set `network.address` to your LAN IP.
- **VS200 not found**: press a button to wake it (it sleeps after ~30 min); make sure it is not
  connected to the trainer or another app.
- **Something odd**: run `run.cmd --debug` and look at `%APPDATA%\vs200-steer\vs200-steer.log`.

## Credits

Protocol knowledge from [BikeControl](https://github.com/OpenBikeControl/bikecontrol). See NOTICE.
```
